## Conceptual answers captured today (for future you)

### Semantic drift / A→B→A / “A with B implied”

- **Bind** picks one hop; **L1** is that hop only.
- Return-to-A revives **A’s** asserted package — not A∪B mash.
- Cross-hop implication is **catalog/rollup/opt-in import** (or an explicit future merge law), not a new cosine blend.
- Agent stacks mostly **summarize** or **extract→ADD/UPDATE/DELETE** — that is runtime context distillation, not weight KD. We use RB-WSR + structured rollup instead of transcript stuffing.

### What “good” Select looks like here

High genre confusion + weak identity → **CLARIFY**.  
Strong Dist−Share / slots → bind by \(d\).  
Never: retrieve-and-stuff siblings into generate.
